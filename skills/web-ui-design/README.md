# web-ui-design

Sumiya's portable **web** UI design taste — the web sibling of `mobile-ui-design`.

A calm, premium fintech aesthetic captured as enforceable rules, so any web UI (Nuxt/Vue, React/Next, Tailwind, NuxtUI/shadcn, plain HTML) lands consistent and non-generic. Born from the insure mini-app redesign (2026-06); meant to be reused across every web project, including the web-admin refactor.

- **The system + rules:** [SKILL.md](SKILL.md)
- **Scope:** web only. Native mobile → `mobile-ui-design`. Generic greenfield exploration → `frontend-design`.
- **It's living:** update SKILL.md whenever a new preference, approved design, or proven pattern appears.

The five levers: **depth not flat · token discipline · tight geometry · color as accent · honest hierarchy + states** — applied in light and dark.
